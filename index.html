          โปรโมชั่นรายเดือน

          Claude เสนอโปรของแต่ละร้านทีละเดือน ร้านละ 5 ตัวเลือกต่อเดือน: 3 ตัวจากโปรที่เคยได้ผลจริงและวันสำคัญ + 2 ตัวอ้างอิงจากโปรที่ร้านเพื่อนในปัตตานีใช้จริง · เป็นข้อเสนอ ต้องเช็กต้นทุนกับร้านก่อนใช้

          ทำคอนเทนต์

          งานกราฟิก

          Claude คิดภาพและเขียน prompt ให้ร้านละ 4 ชิ้น อิงจากโปรรายเดือนและปฏิทิน · คัดลอกไปสร้างภาพใน ChatGPT

          วิธีใช้
          1. กด “คัดลอก prompt ไปใช้ใน ChatGPT”
          2. เปิด ChatGPT แนบรูปโลโก้ร้าน แล้ววาง prompt ส่งได้เลย
          3. ถ้าตัวหนังสือไทยในภาพเพี้ยน ให้พิมพ์ต่อว่า “ทำภาพเดิมแต่ไม่มีตัวหนังสือ” แล้วไปใส่ข้อความเองใน Canva

          วิดีโอสาขา

          Claude คิดไอเดียคลิปให้แต่ละสาขา พร้อมรายการช็อตที่ต้องถ่าย · พนักงานสาขาอัปโหลดคลิปดิบที่นี่ แล้ว Claude ตัดต่อให้

          ขั้นตอน
          1. พนักงานสาขา: เลือกสาขา → ดูไอเดีย → ถ่ายตามช็อต (แนวตั้ง) → กด “อัปโหลดคลิป” · คลิปใหญ่แค่ไหนก็ได้ ระบบย่อให้อัตโนมัติ (คลิปละไม่เกิน 3 นาที ระหว่างย่อเปิดหน้าจอค้างไว้)
          2. ทางร้านหลัก: พิมพ์ในแชทกับ Claude ว่า ตัดวิดีโอสาขา … ให้หน่อย
          3. Claude: ดึงคลิปจากที่นี่ ต่อคลิป ตัดให้กระชับ ใส่ข้อความ hook แล้วอัปกลับมา ขึ้นสถานะ “ตัดแล้ว” พร้อมปุ่มดูวิดีโอ
